# Biggieware

A Minecraft 26.3 client mod for Fabric with its own Windows launcher: 92 cheats in a pink
in-game menu (Right Shift), plus a texture pack browser.

## Install

Download `BiggiewareLauncher.exe` from the [latest release](../../releases/latest), run it and
click Install. The launcher keeps itself up to date: when a new version is out, PLAY turns
into an UPDATE button.
